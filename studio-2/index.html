STUDIO PROYEK 2 · IF25-40401

Kompetisi Klasifikasi Sampah

Latih model CNN untuk mengenali lima jenis sampah yang paling sering kita temui di Indonesia — dari gelas plastik air mineral sampai bungkus mi instan. Nilai Studio 2 kelompok Anda ditentukan oleh performa model pada validation set tersembunyi yang hanya dipegang tim pengajar.

Kelompok maks. 3 orang 3× preview skor Final: Minggu, 25 Okt 2026 Metrik: Macro-F1 Bobot: 10% nilai akhir
Nilai berbasis performa. Nilai Studio 2 dihitung dari skor Macro-F1 model kelompok pada validation set tersembunyi di putaran Final (25 Oktober 2026), dikonversi dengan ambang nilai yang diumumkan kemudian (lihat Penilaian). Skor Preview 1 dan Preview 2 hanya umpan balik dan tidak memengaruhi nilai.

Tugas

Bangun model klasifikasi citra yang menerima satu foto sampah dan memprediksi salah satu dari lima kelas di bawah. Anda bebas memilih pendekatan: CNN from scratch seperti di Pertemuan 4, arsitektur modern dari Pertemuan 5, atau fine-tuning backbone pretrained ImageNet sesuai materi Studio 2. Data tambahan dari luar juga diperbolehkan.

Kelompok tidak pernah melihat validation set. Asisten dosen yang menjalankan model (model.pth) kelompok Anda pada validation set menggunakan skrip evaluate.py yang sama persis dengan yang ada di starter kit, lalu mencatat skornya di Google Sheets skor kelompok.

Dataset

Train set berisi ±2.900 gambar dalam 5 kelas, dikumpulkan dari web lalu dibersihkan (deduplikasi, penyaringan otomatis, dan pemeriksaan manual oleh asisten). Validation set (±740 gambar) berasal dari pengumpulan yang sama, dipisahkan secara acak dan disimpan oleh tim pengajar. Label masih dapat mengandung sedikit noise — menangani hal itu adalah bagian dari tantangan.

Aturan

  1. Kelompok beranggotakan maksimal 3 orang. Daftarkan nama kelompok, anggota (nama + NIM), dan tautan repo GitHub kepada asisten dosen sebelum tenggat Preview 1.
  2. Repo GitHub wajib publik sejak pendaftaran hingga nilai diumumkan. Seluruh kode pelatihan dan submission berada di repo ini.
  3. Lacak progres lewat commit. Commit secara berkala selama pengerjaan — riwayat commit dipakai untuk melacak progres kelompok. Jangan mengunggah seluruh pekerjaan dalam satu commit di menit terakhir.
  4. README wajib jelas dan memuat: nama kelompok, nama lengkap dan NIM seluruh anggota, ringkasan pendekatan, sumber data tambahan (jika ada), dan cara reproduksi. Gunakan README_TEMPLATE.md.
  5. Pendekatan bebas: CNN from scratch, backbone pretrained (torchvision / timm), maupun data tambahan dari luar diperbolehkan. Cantumkan sumber data tambahan di README.
  6. Format submission wajib mengikuti kontrak di bagian Format Submission. Submission yang gagal dijalankan oleh evaluate.py tidak mendapat skor pada putaran tersebut.
  7. Batas teknis: berkas model.pth maksimal 500 MB dan evaluasi seluruh validation set harus selesai dalam 15 menit. Bila bobot > 100 MB (batas GitHub), lampirkan sebagai aset GitHub Release atau Git LFS dan tulis tautannya di README.
  8. Integritas: berbagi kode, bobot model, atau prediksi antarkelompok tidak diperbolehkan. Pelanggaran ditindaklanjuti sesuai aturan akademik ITERA.

Terminal
python evaluate.py --submission ./submission --data ./my_val

Starter Kit

  • evaluate.py — skrip evaluasi resmi (identik dengan milik asisten): Macro-F1, akurasi, F1 per kelas, confusion matrix.
  • submission/model.py — contoh submission ResNet-18.
  • train_baseline.py — baseline fine-tuning ResNet-18 yang otomatis membuat split my_val/ dan menyimpan submission/model.pth.
  • README_TEMPLATE.md — templat README repo kelompok.

Baseline ResNet-18 pretrained (8 epoch) mencapai Macro-F1 sekitar 0,92 pada validation set tersembunyi. Targetkan melampaui angka ini.

Evaluasi & Penilaian

Macro-F1 adalah rata-rata F1 dari kelima kelas, sehingga setiap kelas berbobot sama:

F1_k     = 2 · Precision_k · Recall_k / (Precision_k + Recall_k)
Macro-F1 = (F1_botol + F1_gelas + F1_kertas + F1_saset + F1_styrofoam) / 5

Nilai Studio 2 (skala 0–100) ditentukan oleh Macro-F1 putaran Final dengan ambang absolut — bukan peringkat. Semua kelompok bisa mendapat nilai penuh.

Tabel ambang nilai diumumkan kemudian.

Submission yang tidak dapat dijalankan pada putaran Final, repo yang tidak publik, atau README tanpa NIM anggota tidak dapat dievaluasi.

FAQ

  • Boleh pakai Kaggle / Google Colab? Boleh. Setelah selesai berlatih, unduh model.pth dan commit ke repo.
  • Boleh memakai timm atau library lain? Boleh. Tulis paketnya di submission/requirements.txt; asisten memasangnya di environment terpisah. Paket dasar yang selalu tersedia: torch, torchvision, timm, pillow, numpy.
  • Kenapa skor preview berbeda dengan validasi lokal? Split lokal Anda kecil dan bisa jadi lebih mudah atau lebih sulit. Gunakan validasi lokal untuk memilih model, dan skor preview untuk mengecek generalisasi.
  • Commit kami terlambat beberapa menit dari tenggat. Asisten akan mengevaluasi commit terakhir sebelum tenggat. Jika tidak ada, kelompok tidak mendapat skor pada putaran tersebut.
  • Bolehkah mengganti anggota kelompok? Hubungi asisten dosen sebelum Preview 1.
