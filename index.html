Deskripsi Singkat Mata Kuliah

Mata kuliah Deep Learning membekali mahasiswa dengan fondasi teoretis dan keterampilan praktis untuk merancang, melatih, dan mengevaluasi model pembelajaran mendalam menggunakan PyTorch. Perkuliahan berjalan dari dasar jaringan saraf (perceptron, MLP, fungsi aktivasi, loss, dan optimasi) menuju arsitektur modern: convolutional neural network (CNN) dan variasinya, pemodelan sekuensial (RNN, LSTM, GRU), transformer untuk NLP dan computer vision, model generatif (autoencoder, GAN), hingga topik frontier (reinforcement learning, graph neural network, Mamba). Perkuliahan diakhiri dengan proyek kompetisi Kaggle dan sesi poster sebagai luaran tugas besar.

Capaian Pembelajaran Mata Kuliah (CPMK)

  • CPMK 1 — Mahasiswa mampu menjelaskan konsep dasar deep learning (perceptron, MLP, aktivasi, loss, optimasi) serta cara kerja arsitektur modern (CNN, RNN/LSTM/GRU, Transformer, dan model generatif).
  • CPMK 2 — Mahasiswa mampu merancang, melatih, dan mengevaluasi model deep learning menggunakan PyTorch untuk masalah klasifikasi, regresi, dan pemodelan sekuensial.
  • CPMK 3 — Mahasiswa mampu menerapkan deep learning pada kasus nyata (computer vision, NLP) melalui kompetisi Kaggle dan mengkomunikasikan hasilnya dalam bentuk paper serta poster ilmiah.

Training Deep Learning Model (1)

Capaian Pembelajaran

  1. Memilih fungsi loss untuk regresi vs klasifikasi.
  2. Membandingkan optimizer dan mekanisme adaptifnya.
  3. Mengatur learning rate scheduler untuk menstabilkan konvergensi.
  4. Menerapkan early stopping untuk mengendalikan overfitting.

Pokok Bahasan

  • Loss Function: MSE, MAE (regresi); Cross-Entropy, BCE (klasifikasi).
  • Optimizer: SGD, momentum, AdaGrad, RMSProp, Adam, AdamW.
  • Scheduler: step decay, cosine annealing, warm-up, ReduceLROnPlateau.
  • Early Stopping: validation loss, patience, checkpoint model terbaik.

Bentuk & Metode

  • Kuliah tatap muka
  • Hands-on di kelas
  • Belajar mandiri
  • Tugas terstruktur

Estimasi Waktu

  • TM: 3×50′
  • TT: 3×60′

Pengalaman Belajar
